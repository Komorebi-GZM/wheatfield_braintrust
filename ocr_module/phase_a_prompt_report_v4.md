## 5. 判读

1. **臆造模板可被提示词压住，两次复现。** `## 山东大学`、`1. 输入 / 2. 输出 / 3~5. 处理` 这类自造标题在 A、B 下都消失：微调臂小标题总数 139 → 7，重复条目占比 26% → 0.9%，235955 从 6 个自造标题归零。这是本轮最硬的结论：**模板臆造由提示词触发，不是权重或解码的必然**。
2. **"加'不要省略'能治欠生成"这个判断只对基座臂成立。** 微调臂的字数/参考从 0.68（A）只升到 0.70（B），几乎没动；235955 反而更短（640 → 543 字）、CER 从 0.876 恶化到 1.238。真正被 B 救回的是基座臂（宏 CER 0.915 → 0.857，触顶页 3 → 1）。
3. **宏平均会造成误读，必须配合逐页看。** B 的微调宏 CER（1.017）是三者最低，但 B **一页都没赢**——它只是因为"每次都不极端差"在 5 页均值上占便宜。反之 A 赢 2 页却因 000005（1.600）被拉高。样本只有 5 页，均值方差很大。
4. **公式维度仍是冻结指令最好。** 微调臂含公式宏 CER：冻结 0.775 < B 1.041 < A 1.085。两条改写指令都在压掉公式，这与"公式被 `plain_text()` 剔除后正文 CER 变好看"是同一枚硬币的两面——只看正文 CER 会系统性高估提示词改写的收益。
5. **欠生成是真的，但不是提示词能修的。** 微调臂在 A/B 下 5 页全部低于参考长度（0.44–0.75 倍），说明模型在"不要补充"的约束下倾向于少写；再叠加"不要省略"也没能把它拉回来。这更像是训练信号/解码策略的问题，而不是措辞问题。

---

## 6. 结论

- **A、B 都不能作为新默认指令**。两条改写在压掉臆造模板的同时，都以欠生成和公式丢失为代价；按既定判读规则，三者之间是**混合变化**，任何一方都不能宣称"提示词改进有效"。
- **机制结论可以确定**：模板臆造是提示词可触发的（同 checkpoint、同上限，一句话即可让 6 个自造标题归零）。这条可以写进后续结论，且不依赖宏指标。
- **提示词这条线到此为止**：再改措辞的边际收益已经很低。要治"密集页欠生成/退化"，下一杠杆应是**解码侧**（如重复惩罚、最小生成长度、按页自适应的上限）或**训练侧**（更多步数/更多页），而不是继续堆限定词。
- 若要继续实验，必须先确定判读口径：**报告同时给正文 CER 与含公式 CER，并逐页列胜负**；只看宏平均会被 5 页样本误导。
