# REF
## 置位/复位

$D_7=0$；$D_6D_5$ 任意值；$D_3D_2D_1$：000～111 对应 PC0～PC7；$D_0$：1 SET 置位，0 RESET 复位。

## 21. 8253

工作方式：

- 方式 0（计数结束中断方式）：写入初值后依次减至 0 后完成（倒计时完成中断）。
- 方式 1（可编程单稳触发器）：写入初值后等 GATE 上升沿开始减（触摸延时灯）。
- 方式 2（分频器）：写入初值后，计数器减到 1，输出低，再重装初值。$f_{出}=f_{输入}\div N_{初值}$。
- 方式 3（方波发生器）：类似 2，输出接近对称方波。
- 方式 4（软件选通触发器）：类似 0，一直高，减至 0 低一下回复。
- 方式 5（硬件选通触发）：类 1。

控制字：$D_7,D_6,D_5,D_4,D_3,D_2,D_1,D_0$。

- $D_7D_6$：00 计 0，01 计 1，10 计 2，11 无效。
- $D_5D_4$：00 锁存，供 CPU 读；01 读写低 8 位；10 读写高 8 位；11 先低后高。
- $D_3D_2D_1$：000 方式 0，001 方式 1，X10 方式 2，X11 方式 3，100 方式 4，101 方式 5。
- $D_0$：1 BCD 码，0 二进制计数。

时间常数：$C/T_0=T_0\cdot f_c$。
