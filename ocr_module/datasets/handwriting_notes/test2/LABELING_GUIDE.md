# test2 标注指南（独立测试集）

> 目的：造一个**从未参与过任何调参/诊断**的测试集，用来回答"这套 OCR 到底行不行"。
> 现在的 5 页 test 已被反复观察（`HANDOFF.md` §8 第 2 条），只能当开发集；`test2` 必须是新的。

## 0. 三条硬规则（比格式更重要）

1. **标注时不要去看旧的 `splits/test.jsonl`、`val.jsonl` 或 `annotation_template.jsonl`。** 看过就会不自觉对齐，独立性就没了。
2. **不要改笔记。** 原文写错、写漏、涂改，都照原样转写；不要"顺手修正"成正确知识。
3. **不要补、不要概括。** 只写图上看得见的内容；看不见就用 `□`，整块看不清就写 `> [无法辨认：区域描述]`。

## 1. 操作步骤（问答式，推荐）

每页会生成一份**填空问卷**，你只回答问题，工具把答案组装成标准标注。

```powershell
cd E:\ocr\wheatfield_braintrust\ocr_module

# ① 把新页照片放进这个文件夹（jpg/png 都行，文件名随意）
#    datasets/handwriting_notes/test2/images/

# ② 为每张图生成问卷（不会覆盖已存在的）
python scripts/test2_tool.py form

# ③ 在 datasets/handwriting_notes/test2/answers/ 里打开 <同名>.form.md，
#    只在每题 "A" 后面写答案；不需要的题写「无」

# ④ 把答案组装成标注
python scripts/test2_tool.py assemble

# ⑤ 检查 + 生成清单
python scripts/test2_tool.py check
python scripts/test2_tool.py build --mark-reviewed
```

问卷长这样（每题一行问题 + 一个 `A`）：

| 题 | 问的是什么 | 怎么答 |
|---|---|---|
| Q1 | 这页的标题或编号 | 照抄图上编号（如 `1-1 传感器定义`）；没有就写「无」 |
| Q2 | 正文写了什么 | 按图上顺序一条一行；看不清的字写 `□` |
| Q3 | 有没有表格 | 每行写成 `| 单元格 | 单元格 |`；没有写「无」 |
| Q4 | 有没有公式 | 行内 `$...$`，独立一行 `$$...$$`；没有写「无」 |
| Q5 | 有没有红笔批注/页边注 | 直接写内容；没有写「无」 |
| Q6 | 有没有插图/框图/示波器截图 | 写 `> [图示：简述]`；没有写「无」 |

> 也可以不用问卷：直接写 `answers/<同名>.md`（自由格式），`check`/`build` 同样接受。

`check` 会打印每页的字数、`□` 数量、公式数量与状态（是否已填问卷、是否已组装）；有缺页/空页/TODO 就返回非零，`build` 会拒绝执行。

## 2. 每页写什么（格式）

- **纯 Markdown + LaTeX**，不要加代码围栏包整页，不要写"以下是转写"这类前后缀。
- **标题**：按图上实际编号写，例如 `## 1-1`、`## 3-2`；图上没有标题就不要造。
- **分点**：`-` 或 `1.`，保留嵌套。
- **表格**：用 Markdown 表格语法（`| a | b |` + 分隔行），不要用文字描述表格。
- **公式**：行内 `$...$`，独立成行 `$$...$$`；用合法 LaTeX（`\frac{a}{b}`、`\int_0^1`）。
- **看不清**：单字 `□`；整块 `> [无法辨认：右上角手写批注]`。
- **插图/示意图**：不描述内容，写 `> [图示：电路框图]`。
- **红笔批注/页边注**：当成正文的一部分转写，位置按阅读顺序插入。

## 3. 一个例子

图上是（示意）：

```
## 2-1  测量电桥
R1、R2 为固定电阻，R3 为可调电阻。
当 R1/R2 = R3/R4 时电桥平衡，U0 = 0。
（页边红字：注意 R4 是应变片）
```

对应的答案文件应写成：

```markdown
## 2-1 测量电桥

R1、R2 为固定电阻，R3 为可调电阻。

当 $R_1/R_2 = R_3/R_4$ 时电桥平衡，$U_0 = 0$。

注意 R4 是应变片
```

要点：编号保留、公式用 `$`、红字单独成行但不要加"（页边红字：…）"这种解释——直接写内容。

## 4. 常见错误（都会在验收时被打回）

| 错误 | 为什么不行 |
|---|---|
| 把"□"换成猜的字 | 等于伪造真值，指标会虚高 |
| 把整页概括成三句话 | 长度差太多，CER 直接失真 |
| 顺手把公式改成正确形式 | 参考与图片不符，模型"照着图写"反而被判错 |
| 漏掉红笔批注、页边注 | 漏抄会让"漏识别"看起来像模型的错 |
| 表格写成"共 3 行 4 列" | 评测要求 Markdown 表格 |
| 一页里混入多页内容 | 必须一图一文件，按文件名对应 |

## 5. 每页写完的自检清单

- [ ] 图上每个编号/小标题都出现了，且没有多出来的
- [ ] 每条要点都在，没有概括成一句
- [ ] 表格是 Markdown 表格
- [ ] 公式都用 `$`/`$$` 包住，且成对（`check` 会统计数量）
- [ ] 看不清的字是 `□` 而不是猜的
- [ ] 没有 `TODO` / `待补` 之类的占位（`check` 会报）

## 6. 建议规模与挑选

- **8–15 页**，越多结论越稳；低于 8 页时只能报"个案"。
- 尽量覆盖不同版式：纯文字页、含表格页、含公式页、字迹潦草页各来几页。
- 同一门课、同一批笔记即可，但**不要挑已经被前面实验用过的 23 页**。

- `test2/answers/` 会入库（它是评测输入）；转写内容与原图同等敏感，入库前请确认可以公开。
