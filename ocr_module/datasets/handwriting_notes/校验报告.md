# 照片 OCR 数据集校验报告

- 数据集目录：`照片ocr/`
- 校验时间：2026-11-05
- 用途：手写课程笔记结构化 OCR（Xiaomi-OCR-0 QLoRA）训练/评测数据

## 1. 组成

| 类型 | 数量 | 说明 |
|---|---|---|
| JPG 照片 | 23 张 | 手机拍摄手写笔记，102.6 MB |
| PDF | 2 个 | `物理。.pdf`（12 页）、`题型归纳.pdf`（8 页），疑为打印版/习题参考 |
| 相册数据库 | 1 个 `.db` + `.db-journal` | Android MediaStore 元数据，**非数据，勿入库** |
| 合计 | — | 目录约 171 MB |

## 2. 图片校验结果

- ✅ 23/23 **可正常解码**，无损坏；
- ✅ **无重复**（内容哈希无碰撞）；
- ✅ 分辨率：`3072×4096` / `4096×3072`（≈12MP），模式均为 RGB；
- 方向：竖拍 8 张、横拍 15 张（混合，已用 EXIF 方向校正）；
- 单张 3.8–5.3 MB。
- 明细见 `照片ocr/图片清单.csv`。

## 3. 内容适配性

- 内容为**手写中文物理/电子学课程笔记**，带编号层级（1-1、1-2、5-3、5-5…）、要点式短句、少量公式；
- 与任务目标（保结构 + 保公式的手写笔记 OCR）**高度匹配**；
- 页面为横线笔记本、蓝色桌面背景、右下角有 `HONOR Magic6` 水印。

## 4. 问题与风险

1. 🔴 **无标注**：目前只有图片，**没有 `image→markdown` 标注**，无法直接监督训练。这是当前唯一硬阻塞。
   - 缓解：2 个 PDF（12+8 页）疑为对应打印版/习题，可作**标注参考草稿**（仍以手写照片为准，逐页核对）。
   - 需产出 `ocr_module/data/annotations/real.jsonl`（整页级，保结构/公式，不可辨认用 `□` 不臆造）。
   - 已生成空白模板：`照片ocr/annotation_template.jsonl`（23 条，`markdown` 待填）。
2. 🟡 **分辨率过高**：12MP 远超训练 `max_pixels≈1M`。建议预处理缩放到**长边 1600–2048**（保公式细节），省显存、加速、并作为训练输入；评测可用同尺度。
3. 🟡 **相册数据库文件**（`.db`/`.db-journal`）与 PDF 不应混入训练数据目录；入库/打包前需排除。
4. 🟡 方向混合 + 纸张透视：训练/推理前统一做 EXIF 校正；透视可保留（数据增强）。

## 5. 可用性结论

- **图像质量达标、内容匹配**：✅ 数据集可用于 OCR 任务。
- **但不能直接训练**：缺标注 → 需先完成 20–30 页整页级标注（可用 PDF 辅助起草）。
- 建议流程：`照片ocr/` 23 张 → 缩放到长边 ~1600 → 填入 `annotation_template.jsonl` → `ocr_module/data/{raw,annotations}` → `prepare_dataset.py` → 训练。
