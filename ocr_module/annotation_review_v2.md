## 1. 方法与限制

1. 23 张原图全部打开目视，逐页核对：编号是否存在、条目数量、数字与单位、公式符号、列表写法、涂改与遮挡。
2. 对 4 处关键字符做了旋转/裁切放大（原图 12MP，直接预览时单字不足 3px，必须放大才能定字符）：
   - `000028` 红字段 → 确认 `A₁ A₀{300 uA／10□u B／40 n C`
   - `000037` 置位/复位行 → 确认 `D7=0，D6D5 任意值`
   - `235946` 传送指令块 → 确认 ①~⑧ 八条原话
   - `200907 / 200911 / 235922` 整页旋转后通读
3. **限制（必须写明）**：本报告的"忠实"指**未发现与图矛盾**、且编号/条数/数值/公式/专有名词对得上，**不等于逐字确认**。竖排小字页（200907/200911/200914 等）在可用分辨率下，个别汉字仍可能有偏差；这类页已在第 4 节列为"逐字未确认"。
4. 判定口径：
   - **忠实**：内容与图一致，未发现增删或改写；
   - **修正**：发现内容错误/漏抄/结构自造，已在 v2 改正；
   - **存疑**：改动依据为中等置信（多处读法一致但未取得清晰放大图）。

## 6. 与远程版（`data/annotations/real.jsonl`）的关系

- 该文件未被任何 split 引用，仅作对照线索，**未参与本次修正**。
- 逐页抽验表明：远程版在 200907（5-3 写成"螺管式差动变压器式"）、200914（Δx 写 20mm）、200858（5.119→2.119）等处**确实读错**；在 200843 处**误判图片截断**。
- 因此"远程版 `□` 多 = 更忠实"不成立，"本地版 `□` 少 = 有补写"也不成立。判断只能回到原图，本报告即按此执行。
- 但远程版仍有价值：它记录了红字/涂改/透印等版式线索，可作为第二轮人工校对的提示清单。
